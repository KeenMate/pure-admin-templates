# Changelog

## 1.0.0 — 2026-04-03

### Added
- Initial release with two templates
- `svelte-sveltekit`: SvelteKit + Pure Admin with file-based routing and SSR
- `svelte-spa`: Svelte SPA + Pure Admin with hash-based routing via svelte-spa-router
- Both templates include:
  - Optional features: profile panel, settings panel, font-awesome, floating-ui, page loader, footer
  - Page generators: dashboard, list, detail, form, master-detail
  - Package manager placeholders (pnpm/bun/npm)
  - `data-pa` marker system for feature stripping
  - `template/` subfolder structure separating tooling from project files
